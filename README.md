# Healthcare Insurance Claims Analysis

## Overview

This project presents a comprehensive Exploratory Data Analysis (EDA) of a Healthcare Insurance Claims dataset. The objective is to analyze healthcare claim submissions, approvals, rejections, revenue generation, insurance provider contributions, and department performance to derive actionable business insights.

The analysis was performed using Python and various data analytics libraries, focusing on data cleaning, visualization, statistical analysis, and business intelligence.

---

## Project Objectives

- Analyze healthcare insurance claim patterns
- Understand approval and rejection trends
- Evaluate department-wise and doctor-wise performance
- Identify top insurance providers by claim contribution
- Examine outstanding, accepted, and rejected claim amounts
- Generate business insights through data visualization
- Support decision-making using data-driven analysis

---

## Dataset Information

### Dataset Size

### Dataset Contains

## Key Findings

- Certain departments generate significantly higher claim submissions.
- A small number of doctors contribute a large portion of overall claim value.
- Insurance providers differ considerably in claim approval and rejection rates.
- Submission amounts show clear trends across departments and time periods.
- Correlation analysis helps identify relationships among financial metrics.
